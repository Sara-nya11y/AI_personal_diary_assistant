# 📖 AI Personal Diary Assistant

## 📌 Project Overview

AI Personal Diary Assistant is a Streamlit-based web application that helps users maintain a digital diary. The application uses the Groq LLM API to analyse diary entries, detect the user's mood, generate a summary, and provide positive suggestions.

---

## 🎯 Problem Statement

People often write daily journals but find it difficult to understand their emotional patterns. This project uses Artificial Intelligence to analyse diary entries and provide meaningful insights.

---

## ✨ Features

- 📝 Write daily diary entries
- 💾 Save diary entries
- 😊 AI Mood Detection
- 📄 AI-generated Summary
- 💡 Positive Suggestions
- 📅 Date-wise diary recording
- 🤖 Powered by Groq LLM

---

## 🚀 Installation

1. Clone the repository.

2. Install the required packages.

```
pip install -r requirements.txt
```

3. Add your Groq API Key in the `.env` file.

```
GROQ_API_KEY=your_api_key_here
```

4. Run the application.

```
streamlit run app.py
```

---

## 📖 How to Use

1. Open the application.
2. Write your daily diary entry.
3. Click **Save Diary**.
4. Click **Analyse Diary**.
5. View your mood, summary, and positive suggestions.
